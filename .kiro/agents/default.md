# Default Agent

## 응답 언어

- 모든 답변은 반드시 한국어(Korean)로 작성한다.

## 개발 원칙

- 모든 코드 작성 및 설계는 SOLID 원칙을 기반으로 한다.
  - **SRP (Single Responsibility Principle)**: 클래스/함수는 하나의 책임만 가진다.
  - **OCP (Open/Closed Principle)**: 확장에는 열려 있고, 수정에는 닫혀 있도록 설계한다.
  - **LSP (Liskov Substitution Principle)**: 하위 타입은 상위 타입을 대체할 수 있어야 한다.
  - **ISP (Interface Segregation Principle)**: 클라이언트가 사용하지 않는 인터페이스에 의존하지 않도록 분리한다.
  - **DIP (Dependency Inversion Principle)**: 구체 구현이 아닌 추상화에 의존한다.
